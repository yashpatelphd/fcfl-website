The Futuristic Cyber Forensics Lab (FCFL) researches how to secure robots, metaverse platforms, physical AI, cyber-physical systems and IoT devices, and how to recover and analyse evidence from them after an attack or misuse. We also train the investigators who rely on these methods.

About the lab

FCFL, at the School of Cyber Security and Digital Forensics (SCSDF), National Forensic Sciences University, studies the security and forensics of technologies that are only now entering everyday life: robots, the metaverse, physical AI, cyber-physical systems and connected devices. We turn what we learn into methods, tools and training that investigators can rely on.

Vision

A national reference centre for the security and forensics of emerging technologies.

Mission

  • Research and validate court-ready methods and open tools.
  • Train students, faculty and officers under ISEA Phase-III.
  • Build cyber hygiene awareness among citizens.

Research areas

Eight focus areas, grouped by technology. For each emerging technology we study both sides: how to secure it, and how to investigate it after an attack or misuse.

Robotics security and forensics

Defence, medical, industrial and service robots combine software, sensors and physical motion. A compromised robot can cause real harm, and its logs may be the only record of what happened.

Security

  • Attacks on robot operating systems (ROS 2) and their messaging
  • Sensor spoofing and manipulation of navigation
  • Secure updates and access control for robot fleets

Forensics

  • Recovering mission logs, sensor data and command history
  • Reconstructing a robot's actions before an incident
  • Attributing malicious commands to an operator or attacker

Methods

  • ROS 2 security
  • Sensor data analysis
  • Log reconstruction
  • Robot testbeds

Metaverse security and forensics

Virtual worlds and XR headsets bring new forms of identity, property and harassment, and new places where evidence lives.

Security

  • Avatar identity theft and impersonation
  • Privacy of motion, eye-tracking and biometric data
  • Fraud involving virtual assets and in-world payments

Forensics

  • Artefact recovery from VR/AR headsets and companion apps
  • Reconstructing user sessions and interactions in virtual spaces
  • Evidence of harassment and abuse on immersive platforms

Methods

  • XR device forensics
  • Avatar authentication
  • Virtual-asset tracing
  • Platform log analysis

Physical AI security and forensics

Physical AI puts learning models inside machines that sense and act in the real world, from autonomous robots to smart manufacturing. Their decisions must be protected, and explainable after the fact.

Security

  • Adversarial attacks on perception (vision, lidar, audio)
  • Poisoning and tampering of on-device models
  • Secure model deployment at the edge

Forensics

  • Recovering the model version, inputs and decision behind an incident
  • Detecting tampered or substituted models
  • Explaining an AI-driven action to an investigator or court

Methods

  • Adversarial ML
  • Model forensics
  • Edge AI
  • Explainability

Cyber-physical security and forensics

3D printers, smart displays, smart interactive displays and digital signage connect software to physical output in offices, classrooms and public spaces. They store designs, sessions and content that matter in an investigation.

Security

  • Malicious print jobs and firmware tampering in 3D printers
  • Hijacking of smart and interactive displays
  • Unauthorised content pushed to digital signage networks

Forensics

  • Recovering print history, G-code and design files from 3D printers
  • Extracting user, session and content logs from smart displays
  • Tracing who published content to a signage network, and when

Methods

  • 3D printer forensics
  • Firmware analysis
  • Display and signage logs
  • Content management systems

IoT security and forensics

Smart homes, wearables and connected sensors keep detailed records of people's lives, often on devices with little built-in security.

Security

  • Vulnerabilities in firmware and companion apps
  • Securing device-to-cloud communication
  • Lightweight authentication for constrained devices

Forensics

  • Extracting data from devices, hubs and cloud accounts
  • Correlating timelines across several devices
  • Recovering evidence without altering the device

Methods

  • Firmware analysis
  • Device extraction
  • Cloud artefacts
  • Timeline correlation

Memory forensics and malware analysis

Many modern attacks never touch the disk. We analyse volatile memory and malicious code to find what ran, who controlled it and what it took.

Memory forensics

  • Acquiring memory from live and virtualised systems
  • Detecting fileless malware and code injection
  • Recovering keys and artefacts of encrypted tools

Malware analysis

  • Static and dynamic analysis in isolated sandboxes
  • Family classification and attribution
  • Indicators of compromise for incident response

Methods

  • Memory acquisition
  • Reverse engineering
  • Sandboxing
  • Threat intelligence

Storage and file-system forensics

Storage technology keeps changing, and every change affects what investigators can recover.

Storage media

  • Imaging and hashing HDDs, SSDs and flash media
  • Effects of TRIM and wear levelling on recovery
  • Encrypted volumes and self-encrypting drives

File systems

  • Artefacts left by modern file systems
  • Carving fragmented and partly overwritten files
  • Reconstructing user activity timelines

Methods

  • Forensic imaging
  • File carving
  • File-system internals
  • Write blocking

Vehicle and drone forensics

Connected vehicles and drones record location, movement and user data that can decide accident, smuggling and security cases.

Vehicles

  • Infotainment and telematics extraction
  • Linking a vehicle to paired phones and users
  • Event data around collisions

Drones

  • Flight-log and telemetry recovery
  • Reconstructing flight paths from partial logs
  • Identifying the operator and controller

Methods

  • Telematics
  • Flight-log analysis
  • Chip-off
  • GNSS data
